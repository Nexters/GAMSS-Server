# 앱 화면에서 읽은 것

`main.png` 과 `onboarding-1~3.png` 을 보고 정리한 내용. 랜딩은 여기서 벗어나지 않는다.

## 톤

**종이·손그림 콜라주.** 깔끔한 미니멀이 아니다.

- 메모지 + 마스킹테이프, 손글씨
- 테두리가 자로 그은 선이 아니라 **삐뚤빼뚤한 손그림 stroke**
- 캐릭터도 라인 아트(`assets/characters/` 와 같은 그림)
- 로고 손글씨체가 이 톤의 일부다

## 배경

| 화면 | 배경 |
|---|---|
| 메인 | 종이 질감이 깔린 오프화이트 |
| 온보딩 | 질감 없는 흰색 |

`#FFFFFF` 는 온보딩 기준으로는 맞다. 메인의 질감을 랜딩에 가져올지는 별도 결정이 필요하다.

## 카피

핵심 동사가 **"기록하다"가 아니라 "버리다"** 다.

| 출처 | 문구 |
|---|---|
| 메인 헤더 | `{이름}님 오늘도 감쓰에 버려볼까요?` |
| 메인 입력창 | `무슨이야기를 버려볼까요?` |
| 온보딩 1 | `누구한테 말 못할 말이 있다면 이야기해보세요` |
| 온보딩 2 | `6가지의 감정 친구들과 이야기를 이어가보세요` |
| 온보딩 3 | `안좋았던 감정을 비워보세요` |
| 탭 | `보관함` · `홈` · `대화` |

서비스를 줄여서 **"감쓰"** 라고 부른다. 카드 저장소는 **"보관함"**.
사용자 이름에 **형광펜 하이라이트**를 긋는 것이 강조 장치다.

## 온보딩 3장 = 서비스 설명 3단

랜딩 섹션 구조를 그대로 여기서 가져올 수 있다.

1. **말 못할 말** — 메모지 세 장(임금님 귀는 당나귀 귀 / 팀장은 외계인 / 내 귀에 도청장치)
2. **감정 친구 6종** — 캐릭터 카드
3. **비우기** — 쓰레기통에 메모지를 버리는 그림

## 버튼

| 용도 | 색 |
|---|---|
| 보조 진행(`다음`) | `gray-900` 계열 먹색 |
| 최종 CTA(`시작하기`) | 주황 — **더는 쓰지 않는 색이다** |

**주황은 브랜드에서 빠졌다.** 온보딩 마지막 버튼의 주황은 옛 시안이므로 랜딩에 가져오지 않는다.
랜딩의 주 버튼은 먹색(`gray-950`)으로 간다.

## 감정 카드 (`card.png`)

세로 카드 한 장(732 × 1056, 약 1 : 1.44). 구겨진 종이 질감 위에 **굵은 손그림 테두리**.

```
  26.08.03                      [×]     ← 날짜 YY.MM.DD
        [ 캐릭터 라인아트 ]                ← 감정 색, 카드에서 가장 큰 요소
  - - - - - - - - - - - - - - - -        ← 점선
          오늘 화~나네                     ← 감정 문구. 굵게, 먹색
      대화 요약 (3줄, 회색, 가운데)
  - - - - - - - - - - - - - - - -
          GAMSS 로고                       ← 감정 색으로 칠한다
```

**카드 속 캐릭터는 `assets/characters/*.svg` 와 같은 그림이다.** 렌더해서 대조 확인했다 —
따로 카드용 에셋을 받을 필요 없이 가진 SVG 로 랜딩에서 카드를 그대로 재현할 수 있다.

카드 맨 아래 로고는 먹색이 아니라 **그 카드의 감정 색**으로 칠한다. 그래서 로고 SVG 를 쓸 때는
박혀 있는 `fill="#1E1F22"` 를 `currentColor` 로 바꿔 CSS 에서 색을 주도록 한다.

### 감정별 문구

| `EmotionType` | 문구 |
|---|---|
| `JOY` | 오늘 기~쁘네 |
| `SADNESS` | 오늘 슬~프네 |
| `ANGER` | 오늘 화~나네 |
| `ANXIETY` | 오늘 불~안하네 |
| `GRUMPY` | 오늘 까~칠하네 |
| `QUIRKY` | 오늘 엉~뚱하네 |

카드 가운데 캐릭터와 색이 감정에 따라 바뀌고, 문구 아래에는 대화 요약이 들어간다.
