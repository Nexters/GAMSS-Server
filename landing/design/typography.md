# 타이포그래피

## 폰트: Pretendard

라이선스는 SIL Open Font License 1.1 이라 웹 임베딩에 제약이 없다. 앱 폰트와 웹 폰트 라이선스가
갈리는 유료 서체(산돌·윤디자인 등)였다면 별도 확인이 필요했는데, 그 문제가 없다.

**CDN 을 쓰지 않고 woff2 파일을 레포에 넣어 self-host 한다.** 이 페이지는 인스타 인앱 브라우저처럼
환경이 제각각인 곳에서 열리고, 외부 요청을 두지 않는 것이 이 랜딩의 기본 제약이다
(`deploy/nginx/conf/gamss.conf` 상단 참고).

### 서브셋

한글 폰트는 통짜로 받으면 무겁다. Pretendard 가 제공하는 **dynamic subset**(글자 단위로 쪼갠
woff2 + `unicode-range`)을 쓰면 브라우저가 실제로 쓰인 글자 조각만 받는다. 랜딩처럼 텍스트가
적은 페이지에서 특히 이득이 크다.

### 굵기

랜딩에 필요한 만큼만 넣는다. 안 쓰는 굵기를 넣으면 그만큼 그대로 용량이다.

- [ ] 실제로 쓸 weight 확정 (예상: 400 / 600 / 700)
